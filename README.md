# CPP-OOP-Practical-7

C++ OOP programs demonstrating polymorphism using real-life examples.

## Aim
To implement polymorphism in C++ using function overloading and function overriding.

## Concepts Used
- Compile-time polymorphism
- Run-time polymorphism
- Function overloading
- Function overriding
- Inheritance and virtual functions

##About

This practical explains how polymorphism allows the same function name or interface to perform different tasks in C++. It covers compile-time and run-time polymorphism using simple, real-life examples.
